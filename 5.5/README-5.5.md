# Грави-Бум! 5.5

## Основные изменения

- Возвращена **полноэкранная 3D-сцена**. Верхние панели, надписи, игровые кнопки и фон нижнего прогресса прозрачные: звёзды и башня видны за ними. Камера учитывает высоту центральной подсказки, не создавая закрытой цветной области.
- Удалены всплывающие инструкции этажей и их отложенные таймеры. Постоянное задание остаётся сверху. Короткие уведомления о событиях — очках, ошибке, решении — сохранены; на компактном экране одновременно видно не более одного.
- Счётчики «Лунки …», «Труба …», «Плиты …» перенесены в левую группу со статистикой. На телефоне эта группа располагается сверху.
- Справа: Авто → Тряхнуть → Справка → Заново → Этажи → Сброс этажа → Резать трос. Неактуальные кнопки скрываются. Справка выровнена по левому краю, как остальные действия. Разреза и сброса под игровым полем больше нет.
- На компактных/сенсорных экранах действия располагаются сверху **иконками без подписей**, с настоящей областью нажатия 44×44 px, локализованными aria-label и title. Общая группа «Назад / звук / язык / тема» остаётся в одинаковой позиции на всех экранах. На главной место невидимой кнопки «Назад» сохраняется, чтобы остальные не сдвигались.
- Сохранена золотая полоса 0/4 → 4/4 из 5.4, без синей подложки. Срез верёвки остаётся обычным, без оценки качества, очков и штрафов.

## Исправления и полировка

Зафиксирован шар при победе; добавлена защита от преждевременного промаха при входе в финал; трубные шары сохраняют исходное исключение из магии. Перед предложением повтора после погашения плиты — понятное предупреждение и 1,5 секунды замедления. Оно учитывает паузу, рекламу, восстановление плиты и смену игры.

Авто первого этажа получает до 150 секунд; остальные настройки и физические правила не подменяются. Профиль, настройки размеров/скорости, датчики и реплей не возвращены.

Уменьшена повторная работа визуальных эффектов и raycast, сохранено корректное освобождение ресурсов. Восстановлены исходные двухтональные сигналы лунки/отказа. Добавлены схема свайпа в обучении, короткая строка клавиш на ПК, более заметное «Продолжить», название башни в паузе/победе, подсветка личных рекордов и даты новых результатов.

**Полный разбор всех 51 пункта A–J — AUDIT-5.5.md.** В нём отдельно обозначены уже исправленные, неприменимые и непринятые рискованные предложения. Не все исходные утверждения о коде 5.3 соответствовали фактической 5.4.

## Рекорды и совместимость

Старые рекорды и звёзды не обнуляются. Дата сохраняется только при новом улучшении результата, отдельно для честного и Авто рейтинга; облако переносит дату вместе с соответствующим счётом. Для старого результата без даты показывается «—», сегодняшняя дата задним числом не ставится. Рейтинги остаются личными, не глобальными.

## Файлы

- **gravi-boom-v5.5-yandex.zip** — публикационная сборка, index.html в корне.
- **gravi-boom-v5.5-single.html** — один файл для локальной проверки, без SDK и рекламы. Пояснений об этом режиме в интерфейсе нет.
- **gravi-boom-v5.5-complete.zip** — обе сборки, исходная папка публикации, README, аудит, отчёт и журналы.
- **verification/** — JSON/CSV/log, контрольные суммы и воспроизводимый сценарий прохождений.

## Ограничения

Проверки — Chromium/Playwright и программный WebGL, реклама — SDK-заглушка. Физические телефоны, Safari, аппаратный FPS/нагрев, настоящие рекламные показы и реальный облачный аккаунт не проверялись. Нельзя заявлять измеренное ускорение на устройствах или гарантировать модерацию. Перед публикацией необходимы живой платформенный черновик и устройства. В GitHub изменения не отправлялись.
