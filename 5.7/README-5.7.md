# Грави-Бум! 5.7

Выбран пользователем вариант **№2 «Шалфейный»** из пяти показанных фонов.

## Единственное изменение

В светлой теме фон и цвет дальнего тумана — приглушённый серо-зелёный `#9FAFAA` вместо `#EDF2F0`. Декоративное дальнее свечение вокруг башни уменьшено до 30% прежней непрозрачности. Это параметры выбранного предпросмотра, а не численное обещание снижения яркости экрана на 70%.

При возврате к тёмной теме восстанавливаются исходные фон/туман текущего этажа и полное прежнее дальнее свечение. Звёзды, кнопки, текст, цвета игровых объектов, геометрия, освещение объектов и механика не изменены. CSS и Three.js совпадают с 5.6 побайтно. Сохранения совместимы; существующий выбор темы используется по-прежнему.

## Файлы

- `gravi-boom-v5.7-yandex.zip` — публикационный ZIP с index.html в корне.
- `gravi-boom-v5.7-yandex/` — редактируемая публикационная папка.
- `gravi-boom-v5.7-single.html` — один файл без SDK и рекламы; пояснений этого режима в интерфейсе нет.
- `gravi-boom-v5.7-complete.zip` — обе сборки, исходная папка, этот документ, предпросмотры и проверочные материалы.
- `LIGHT-5.7.png` — снимок готовой версии; `SKY-OPTIONS.jpg` — пять предложенных вариантов с исходным фоном для сравнения.

## Проверки поставляемой сборки

- 120 сочетаний: пять размеров окна × шесть экранов × два языка × две темы. Проверены цвета кнопок/значков/обводок, прозрачность игровых панелей, расположение общей панели, отсутствие горизонтального выхода кнопок за экран. Переключение реальными кликами, сохранение после перезагрузки, работа с запрещённым localStorage. Ошибок страницы нет.
- На всех десяти башнях в обоих дистрибутивах проверено многократное переключение: светлый фон/туман `9fafaa`, свечение `.3`; тёмный фон/туман точно совпадают с исходной палитрой, свечение `1`. Публикационный SDK в этом тесте заменён заглушкой.
- 10/10 полных автоматических прохождений, по одному каждой башни, 5 в тёмной и 5 в светлой теме. Ноль перезапусков и ошибок страницы. Отдельная серия 5.7, не результаты предыдущей версии.
- Синтаксис JS и 11 правил ESLint: ноль диагностик. Контрольные суммы, целостность ZIP, корневой index.html, ASCII-пути, отсутствие внешних скриптов/стилей в одном файле проверены при упаковке.

Прохождения: фиксированные seed, шаг симуляции 1/60, штатный Авто включается на этаже и после истечения сеанса. Интро пропущено, звук отключён, отрисовка каждого шага не выполняется. Положения шаров и флаги победы не подставляются. Это не тест ручной сложности или аппаратного FPS. Сценарии и сырые JSON/log — в `verification/`. Для воспроизведения нужны Node.js, Playwright/Chromium; сервер `python verification/serve57.py` обслуживает комплект на порту 8091.

## Публикация и ограничения

Загрузить публикационный ZIP в черновик, обновить версию и скриншоты. Сохранены LoadingAPI/GameplayAPI, RU/EN, добровольный rewarded перед Авто, пауза и отключение звука при рекламе, облачные сохранения. Настройки монетизации и облака в черновике должны соответствовать используемым возможностям SDK.

**В видимом игроку интерфейсе нигде не должно быть надписи «яндекс игры».**

- https://yandex.ru/dev/games/doc/ru/concepts/requirements
- https://yandex.ru/dev/games/doc/ru/console/add-new-game/draft
- https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv

Three.js r170 не изменена; MIT-лицензия приложена и встроена в один файл. Значки встроены, внешних загрузок для них нет. Профиль и настройки не возвращены, рекорды не сброшены.

Проверки — Chromium/Playwright, программный WebGL и SDK-заглушка. Физические устройства, Safari, живые объявления, облачный аккаунт и аппаратная яркость/нагрев не проверены. Нужны реальные устройства и платформенный черновик; модерация не гарантируется. В GitHub изменения не отправлены.
